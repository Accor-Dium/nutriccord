# nutriccord

App móvil (Android / iOS) de conteo de calorías para el ámbito nutrimental, hecha con
React Native + Expo. Usa como referencia el Sistema Mexicano de Alimentos Equivalentes (SMAE).

## Empezar

```bash
npm install
npm start          # abre con Expo Go (escanea el QR) o un development build
npm run android    # emulador / dispositivo Android
npm run web        # versión web
```

Antes de subir cambios: `npm run lint` y `npm run typecheck`.
